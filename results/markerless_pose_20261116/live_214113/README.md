# 임시 카메라 화면 확인

실제 촬영 시각은 summary.json의 capture_wall_clock_iso를 따른다. 원본 촬영 도구의 폴더명에 남은 20261024는 이번 촬영 날짜가 아니다.

큐브 전체와 두 넓은 면이 화면에 들어왔다. 1280×720 MJPG의 새 프레임 세 장을 검사했다. 손으로 지정한 대략적인 탐색 영역을 사용했으며 YOLO 검출 시험이 아니다. 현재 코드에서 세 장 모두 면 격자 검사를 통과하지 못했다. 색상별 분리 후보 두 가지도 통과 수를 늘리지 못해 해당 운영 코드 변경을 정확히 복구했다. 모터 접근·명령은 없었다.

## 남은 항목

- 실제 그림자·반사에서 면 격자 검출 개선.
- 유효한 여섯 면 색상 기준 수집.
- 손목 마커 관측과 실제 좌표·카메라 보정 확인.

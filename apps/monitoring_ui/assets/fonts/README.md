# GUI 글꼴

- `bithumb-gothic-basic.ttf`: 제목과 본문 외 UI 텍스트에 사용합니다. 빗썸고딕 Basic 파일이며, Bithumb 브랜드 서체 페이지에서 배포하는 파일입니다.
- `freesentation-vf.ttf`: 설명 문구 등 본문 텍스트에 사용합니다. Freesentation Variable Font 파일입니다.

## 배포 및 라이선스

- 빗썸고딕은 SIL Open Font License 1.1에 따라 웹과 앱을 포함해 무료로 사용할 수 있습니다. 글꼴 파일 단독 판매는 허용되지 않습니다.
- 프리젠테이션(Freesentation)은 제작자 안내에 따라 SIL Open Font License(OFL)로 제공되며, 글꼴 단독 판매와 라이선스 변경을 제외한 사용·수정·재배포가 허용됩니다.
- 배포처의 최신 조건을 확인하려면 아래 공식 페이지를 참조하세요.

  - 빗썸고딕: https://www.bithumbcorp.com/ko/promotion/font.php
  - 프리젠테이션: https://freesentation.blog/freesentation

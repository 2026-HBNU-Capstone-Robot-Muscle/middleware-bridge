# 모니터링 GUI 기능 정리

1. ROS2 연결 상태: rosbridge 주소와 연결 여부 표시
2. 큐브 인식·풀이 결과: 인식 상태, scan_id, 큐브 상태, 풀이 수열 표시
3. 3D 큐브 시각화: cube_3D_conversion의 구현을 참고해 큐브를 3D로 표시하고 풀이 과정을 미리보기
    - 토글로 관리
        - off(default): ROS 실행 피드백에 맞춰 3D 큐브와 진행 상태를 갱신
        - on: 실물과 별개로 GUI 상에서만 고정된 속도로 풀이 애니메이션 미리보기 실행.
    - 고정 속도 재생: GUI 애니메이션 속도는 사용자가 조절하지 않고 고정
4. 풀이 진행 단위: “오른손 회전 → 오른손 지지 → 왼손 회전”을 한 사이클로 보고, 사이클이 끝나면 큐브 상태와 풀이 진행을 갱신
5. ROS 실행 제어: 선택한 풀이의 실행 요청과 취소
6. 실행 상태 표시: 현재 이동·단계·담당 손·완료·오류 표시
7. dry-run 표시: 현재 실행이 dry-run인지 GUI에서 명확히 표시
    - 토글 관리: dry-run on/off를 통해 실물 연결 여부 결정
        - on: dry-run mode on
        - off: 실물 연결
8. 이벤트 기록: ROS 연결, 풀이 수신, 실행 결과 기록
